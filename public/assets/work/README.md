# SocialHaus work media

Approved client media belongs in a folder per project, for example:

`/assets/work/client-name/campaign-name/hero-film.mp4`

`/assets/work/client-name/campaign-name/hero-poster.webp`

`/assets/work/client-name/campaign-name/editorial-portrait.webp`

Update only `components/work/workMedia.ts` when assets arrive. Images and
videos remain independent from the Chapter 02 layout and motion.
